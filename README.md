# 关于这个仓库的由来和思考：大模型推理系统学习记录

## 契机

在中秋节前，有人在26级年段交流群中发布了一个训练营招募通知，我便加入了训练营并在中秋节三天中完成了其中的任务一并提交了这个仓库，但由于种种原因，包括我还不怎么会使用github，后续任务未完成，因此这里展示的是学习与尝试过程，而非完整的复现实验。
## 简介

本仓库记录我参加中秋训练营时，对大模型推理系统的学习和实践。重点包括 SGLang 的请求处理与前缀缓存、vLLM 的 KV Cache 管理，以及一次环境配置和请求构造实践。

目前仓库主要用于归档学习笔记与过程材料，尚不是包含完整代码和原始数据的复现实验仓库。

## 我完成的工作

- 阅读 vLLM、SGLang 相关资料，整理 PagedAttention、RadixAttention 和前缀复用的基本作用。
- 梳理从客户端请求、Tokenizer、Scheduler、Prefill、Decode 到返回结果的流程，并制作流程图。
- 在 AI 辅助下配置实验环境，尝试提取 Mooncake trace、构造 synthetic prompt 并运行请求；记录环境配置和端口问题及处理过程。
- 总结自己对推理流程的理解，以及实践中仍不清楚的问题。
